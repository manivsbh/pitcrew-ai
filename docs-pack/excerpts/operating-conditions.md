# Operating conditions (verified excerpt)

Source: Bearing DataCenter, "Operating Conditions"
https://mb.uni-paderborn.de/en/kat/research/bearing-datacenter/operating-conditions

Four fixed settings; all three parameters constant within each measurement.
20 measurements of 4 seconds each per setting. Temperature ~45-50 C.

| Set | Speed (rpm) | Torque (Nm) | Radial force (N) | Code |
|---|---|---|---|---|
| 0 | 1500 | 0.7 | 1000 | N15_M07_F10 |
| 1 | 900 | 0.7 | 1000 | N09_M07_F10 |
| 2 | 1500 | 0.1 | 1000 | N15_M01_F10 |
| 3 | 1500 | 0.7 | 400 | N15_M07_F04 |

Filename encoding: `<CODE>_<BEARING>_<REP>.mat`, e.g. `N15_M07_F10_KA01_1.mat`
(source: "Data Sets and Download" page). N = speed/100 rpm, M = torque x10,
F = force/100 N.
