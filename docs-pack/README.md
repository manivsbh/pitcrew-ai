# Documentation pack

Curated, label-free technical excerpts the agent may cite: test-rig setup,
sensor placement, bearing geometry, operating-condition definitions, and
sampling parameters. Each excerpt records its source and location.

Sources (generic technical information only; fault labels never enter the pack):

- PHM Society paper (test-rig and experiments)
- Bearing DataCenter: test-rig and measurement equipment
- Bearing DataCenter: operating conditions

Rule: any passage that reveals a bearing's damage state is excluded.
Retrieved excerpts are covered by label-leakage checks in `tests/`.
