# Centrifugal pump blueprint — Blueprint & Component Specification

## Extracted Dimensions & Ratings
- shaft_diameter_mm: 22.0
- rated_rpm: 2900.0
- max_torque_nm: 28.0

## Confirmed Components
- **Suction Discharge Base (Pos. 1)**: Base housing containing suction/discharge at bottom of stack
- **Stage Impeller (Pos. 2)**: Rotating impeller stages that add pressure
- **Diffuser Chamber (Pos. 3)**: Stationary diffuser chambers around each impeller
- **Pump Shaft (Pos. 4)**: Central vertical shaft driving impellers
- **Cartridge Shaft Seal (Pos. 5)**: Cartridge mechanical seal above pump stack
- **Sleeve O-Ring (Pos. 6)**: O-ring sealing sleeve in stack
- **Coupling Halves (Pos. 7)**: Shaft coupling connecting motor to pump
- **Drive Motor (Pos. 8)**: Top-mounted electric drive motor

## Assembly Sequence
1. Mount Suction Discharge Base as foundation of vertical stack
2. Install vertical Pump Shaft 22 mm through base and stack
3. Stack Diffuser Chambers and Stage Impellers with Sleeve O-Rings
4. Fit Cartridge Shaft Seal over shaft above stack
5. Connect Coupling Halves then mount Drive Motor on top, rated 2900 rpm 28 Nm
